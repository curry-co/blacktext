# Security

Please report a security problem privately by email to [apps@curry.co](mailto:apps@curry.co), not in a public issue. Say what you found, how to reproduce it, and which version of BlackText it affects. You'll get a reply within a few days, and a fix will be released as soon as it's ready, with credit to you if you'd like it.

Only the latest release of BlackText for Mac, iPhone and iPad gets security fixes.

What counts: anything that lets someone other than you read or change your notes, a way around the Mac app's update signature checks, or anything the apps do that the [privacy policy](https://curry-co.github.io/blacktext/privacy/) says they don't.

Not a vulnerability: programs running as you can read the notes file directly, and an AI agent's name is a label it gives itself. The README explains both.
